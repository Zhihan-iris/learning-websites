# Zhihan · 学习网站

## 音量与错题默写次数

- 在练习设置中调整播放音量（0–100%，0% 静音），下一次朗读生效。
- 错题正确默写次数可选 1–10 遍；听力默认 5 遍，写作默认 1 遍。两站分别保存偏好。
- 修改次数用于下一次新错题；正在重写的题目保留原目标及已完成次数，刷新也可继续。
- 听力练习每次正确默写均再次朗读；写作采用中文提示、英文表达，并提供按需发音及搭配用法。错误不计入正确次数，达到目标后仍需另按 Enter 继续。
- 听力的同义替换按整组全部正确计一次；写作搭配回忆也使用此设置；范文错空可单独重练。

以下流程中的固定次数为默认设置示例。


本仓库分别发布三个独立网站：

- [计量经济学学习室](https://zhihan-iris.github.io/learning-websites/econometrics/)：20 个单元、60 道自测、5 个交互实验、公式卡与学习笔记；详见 [计量站说明](../econometrics/README.md)。
- [听力练习室](https://zhihan-iris.github.io/learning-websites/listening/)：原有听力与同义替换练习。
- [写作学习室](https://zhihan-iris.github.io/learning-websites/writing/)：28 个词汇板块、覆盖 1,537 条来源表达的整句与短语学习、27 篇中文提示范文填空；详见 [写作站说明](../writing/README.md)。

各网站的学习记录独立保存。以下为听力练习室说明。

## 使用方式

1. 先选择资料库，再选择分类、每组题数（10 / 20 / 50 / 全部）和顺序，点击「开始今日练习」。
2. 听英语发音，输入单词或短语，按 **Enter** 检查。
3. 答对后自动重读，显示拼写和中文释义，再按 **Enter** 进入下一词。
4. 答错后提示错误、显示正确拼写和中文，并自动加入错题本。
5. 按 **Enter** 隐藏正确拼写，开始 5 遍默写。每次输入后按 Enter，只有正确答案才计数，每次正确都会自动重读（包括第五遍）；写错不增加次数，再次显示正确答案供记忆。
6. 完成 5 遍后，再按 **Enter** 进入下一题。错题记录保留，标记「已巩固」，可在「全部记录」中重新练习。

`Alt + P` 重播当前词。支持英式 / 美式口音与三档速度；设备缺少目标口音时使用可用英语语音。大小写、首尾空格、连续空格不影响判定，常见英美拼写差异可接受。同义替换采用先学习整组、再回忆全部对应表达的流程，填写顺序不限。

## 本地运行

无需安装前端依赖。在仓库目录运行：

```sh
python3 -m http.server 4173
```

打开 <http://localhost:4173/listening/>。不要直接双击 HTML；词库通过 `fetch` 加载，需要 HTTP 服务。

可用 Node.js 运行核心逻辑与词库检查：

```sh
npm test
```

## GitHub Pages

在仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存。根目录有 `.nojekyll`，可直接发布静态资源。

网站地址：<https://zhihan-iris.github.io/learning-websites/listening/>。原根路径会自动跳转到新地址，浏览器学习记录沿用原存储键。

## 数据与隐私

- 使用浏览器 `speechSynthesis` 提供英语读音，不需要 API 密钥。语音是否需要联网由浏览器和所选系统语音决定；网站本身没有语音上传功能。
- 首次播放需要点击开始或播放按钮。若无声，请检查音量、设备英语语音包和浏览器语音支持；刷新后点击声波重播。
- 进度、设置、错题和当前练习（包括重写次数）仅保存在当前浏览器的 `localStorage`。清除网站数据、更换浏览器或设备不会同步进度。
- 「已掌握词汇」统计首次答对或日后复习时直接答对的独立词；完成 5 遍的错词只标记「已巩固」，不会虚增首答正确率。
- 主动「结束本组」会结束当前练习与重写计数，历史答题与错题记录保留。

## 词库来源与整理

来源：用户提供的《雅思听力场景词汇》（新东方在线雅思研发中心），PDF 第 2–20 页，共 **903 条原始表格记录**。封面与推广页不进入词库。原 PDF 不在仓库内。

- `listening/data/source-entries.json`：原始表格提取内容、PDF 页码及位置，便于核对。
- `listening/data/vocabulary.json`：应用实际使用的 966 条练习词。拆开斜杠表达、补全共享的词组部分、展开括号可选形式；同一场景的相同词去重，跨场景同词保留。
- `listening/scripts/build-vocabulary.py`：从原始记录重建应用词库，无第三方 Python 依赖。
- 词库保留英文与中文，并在词库页显示来源页码。
- 修正了明显排印或翻译问题，例如 `four-wheel driver → four-wheel drive`、`stretchclass → stretch class`、`Biophysics → 生物物理学`、`photocopier → 复印机`、`laser printer → 激光打印机`、`nuclear power plants → 核电站`；货币符号补充中文，分拆词汇补充对应释义。完整规则见构建脚本。

## 新增三份资料的练习方式

- **同义替换**：先学习“题目表达 → 对应表达”的完整组及中文释义，再隐藏答案逐项默写所有对应表达。保留 Cambridge 卷号、Test/Part、题号和 PDF 页码。同册的相同题目表达归为一组；这类对应关系依赖题目语境，不表示脱离语境也完全同义。`sb.` / `sth.` 展开为 `somebody` / `something`；停顿省略号无需输入。无需输入句尾标点，但词语仍须匹配本组学习的表达。
- **数字与信息**：原文件仅有答案，没有配套录音；使用英语合成语音练习。电话逐位读数字，人名与邮编逐字母拼读，地址正常朗读，日期使用英语序数词，时间区分 AM/PM。
- 电话输入可有空格、连字符，但必须保留前导 0；邮编忽略空格与大小写，字母 O 和数字 0 不等同；地址支持常见街道缩写；日期支持 `1st January` / `1 January` / `January 1` / `1/1`（日/月）；时间支持 `6.30 am` / `06:30`、`7.30 pm` / `19:30` 和时间范围，错误的 AM/PM 不会被判对。
- **填空考点词**：显示资料中的音标和常用义，英美拼写选项作为可接受答案。合并 `plastic`、`sweetener` 的同册重复记录，保留不同页码。音标按来源保留，朗读使用设备的英语语音。
- 四个资料库都沿用错题本、5 次正确默写和 Enter 进入下一题的流程。不同资料库中的同词是不同练习条目；累计掌握条目按练习 ID 计数。切换资料库时会提示是否结束当前组，历史答题和错题记录保留。

新增资料原始提取内容在 `listening/data/additional-source-entries.json`，应用数据在 `listening/data/additional-books.json`；运行 `python3 listening/scripts/build-additional-books.py` 可重建，只有标准库依赖。原 PDF 不上传仓库。


## 2026-10-19 练习流程更新

- 首次答对后自动重读正确表达；错词巩固每正确默写一次都会再读一次，包括第五遍。
- 同义替换按同一册中的相同题目表达组成学习组。先显示对应表达、释义与原题出处，再隐藏答案逐项默写，顺序不限；需要整组全部正确才通过。
- 错漏显示未回忆出的表达和未匹配/重复填写项，随后整组默写五遍；默写时重播只读题目，避免提前读出答案。
- 分组保留所有原始条目与语境信息；原题对应关系不意味着任意语境下均可互换。
- 旧的答题总数与错题记录迁移保留。若有未完成的旧同义词听写，升级后从相应组的学习页继续；其他资料的练习进度不变。
