# Zhihan · 雅思写作学习室

## 音量与错题默写次数

- 在练习设置中调整播放音量（0–100%，0% 静音），下一次朗读生效。
- 错题正确默写次数可选 1–10 遍；听力默认 5 遍，写作默认 1 遍。两站分别保存偏好。
- 修改次数用于下一次新错题；正在重写的题目保留原目标及已完成次数，刷新也可继续。
- 每次正确默写均再次朗读，错误不计数；达到目标后仍需另按 Enter 继续。
- 听力的同义替换按整组全部正确计一次；写作的搭配回忆和填空也使用此设置。

以下流程中的固定次数为默认设置示例。


独立静态网站，发布地址：<https://zhihan-iris.github.io/learning-websites/writing/>。

与仓库根目录的听力练习室分开：独立页面、界面和浏览器存储键 `zhihan-writing-v1`，不会读取或覆盖听力进度。

## 学习流程

- 高频词汇：听音默写 → 自动复读并显示释义；错误加入错题本 → 查看正确答案 → 隐藏答案 → 正确重写 **1 次** → 单独按 Enter 进入下一题。重写仍错则再次提示，直到写对一次。
- 场景搭配：读用法与例句 → 中文提示回忆 → 语境填空 → 自主造句 → 三项自查。60 个核心表达覆盖 20 个话题，每话题 3 个；其余原文素材在话题页展开阅读。
- 造句仅检测目标表达是否出现，不自动判定语法、逻辑或 IELTS 分数；允许按语境变换词形，最终由学习者自查。
- 本地错题本、刷新续练、1/3/7/14 天间隔复习、搜索、英美口音及语速设置、句子编辑与 Markdown 导出。
- 复习间隔是练习安排，不保证记忆效果或考试结果。网站不发送后台通知。

## 资料与整理

两份用户提供的新东方在线雅思研发中心资料：

| 资料 | 覆盖范围 | 网站内容 |
| --- | --- | --- |
| 雅思写作话题高频词汇 | PDF 第 2–18 页，887 条表格记录 | 903 项练习，28 个分场景；同场景重复项合并，斜杠表达拆分 |
| 雅思写作话题分场景搭配 | PDF 第 3–88 页，20 个话题 | 1,118 条含英文表达的双语素材；60 个核心表达另编例句、用法与造句问题 |

54 条原词汇记录作了拼写、搭配或释义订正，例如 `kidnap` 的中文、`interplanetary travel` 的漏字、`bachelor's degree` 的所有格以及 `low-carb diet` 的含义。每项保留原内容与页码。原文素材中的概括性论点未逐条事实核验，网站对此有明确提示；核心练习使用独立编写的有语境、有条件的例句。

`data/source-vocabulary.json` 和 `data/source-collocations.json` 是提取记录；`data/lessons.tsv` 是编辑后的课程输入；`scripts/build-data.py` 生成 `data/content.json`。不上传原 PDF、封面或推广内容。

```sh
python3 -m http.server 4176 --bind 127.0.0.1
```

## 数据保存与发音

所有记录仅存于当前浏览器，清除网站数据或更换设备后不会同步，请定期导出句子。发音使用设备提供的 `speechSynthesis`；口音和是否需联网取决于浏览器/系统语音。无设备语音时显示提示。

## 验证

核心测试覆盖一次重写、进度恢复、独立存储键、间隔复习、搭配四步流程、自查门槛、拼写变体、887 条源记录覆盖与文本转义。浏览器测试覆盖 Enter 操作、自动复读调用、刷新续练、造句导出、手机布局及听力存储不被改写。自动化测试验证语音调用；实际音色和音量由用户设备决定。
