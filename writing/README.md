# Zhihan · 雅思写作学习室

独立静态网站：<https://zhihan-iris.github.io/learning-websites/writing/>。延续深色与金色配色，与听力练习室分别保存学习记录。

## 学习流程

- **高频词汇**：903 项练习分为 28 个话题板块。成组预习后，看中文写英文，发音按需点击；每批 5、10、20 项或全部未练项，优先继续未练内容。
- **场景搭配**：原资料的 1,537 条表达按 20 个话题、162 个关联小组组织；同一论点中的搭配合成整句，共 327 个整句学习项，加上独立短语共 1,123 个练习项。完整展示英文与中文，整句学习、整句翻译，不再将同一句拆成几道短语题。
- 答对显示释义、结构及用法；答错记入错题本，显示答案与搭配说明，再隐藏英文并按设定次数正确重写。达到次数后另按 Enter 继续。发音只由按钮或 Alt + P 触发，切题与判题不自动播放。
- **怎么用**：预习、素材索引、答案页均可查看词性、搭配结构及介词/词形说明。题目里的提示默认收起，展开前提示会显示英文；完整句子的原搭配可分别查看用法，但不拆成练习题。
- 学完一批可继续本板块、**跳过范文并结束**，或进入关联范文；不强制完成文章。
- **27 篇原创 Task 2 教学范文**关联全部词汇板块与搭配话题，每篇 270–303 词，共 163 个短语或核心论证句填空。相关板块可共享同一范文，自然使用部分表达，不把整个词库硬塞进文章。
- 范文**先显示中文提示**，所有空填完提交后才展示完整参考答案、逐空核对、立场与四段论证思路。支持只重练未匹配的空、整篇重练、草稿保存和学习记录导出。
- 范文按目标表达核对，容忍大小写、常见英美拼写和标点差异；不是任意同义表达的语义评分，也不提供 IELTS 分数。原题与范文为本站教学编写，并非官方范文。
- 原有错题、句子和设置保留。未完成的搭配练习若包含已合并短语，会回到完整句子的预习；新整句成绩单独记录，不把旧短语的完成次数当作整句掌握。旧短语的再练入口也转到对应整句。

整句输入使用多行框：Enter 检查，Shift + Enter 换行；忽略大小写、换行和常见标点差异，但检查完整用词、词形与语序。原文对照注明整句为本站编辑，并非原文逐字引句；有必要时补足主语、订正搭配或限定原文判断。

## 音量与纠错

播放音量 0–100%，0% 静音；纠错重写 1–10 遍，写作默认 1 遍。设置从下一次播放或新错题起生效，正在纠错的目标次数保持不变。范文使用独立的错空重练方式。发音由设备 `speechSynthesis` 提供，实际音色与可用性取决于系统语音。

## 数据与覆盖

| 来源 | 覆盖与整理 |
| --- | --- |
| 用户提供的《雅思写作话题高频词汇》 | PDF 2–18 页，887 条表格记录整理为 903 项，28 个板块；保留原文与页码 |
| 用户提供的《雅思写作话题分场景搭配》 | PDF 3–88 页，1,118 条双语语境、1,537 个提取表达；全部进入 162 个小组 |
| 原版深度搭配课程 | 保留 60 项课程与稳定 ID，兼容旧进度、造句和自查 |
| 新编范文 | 27 篇、163 空；覆盖全部 28 个词汇板块及 20 个搭配话题 |

表达整理订正了明确的拼写、漏字、搭配及中文提示问题；原文与订正备注可在学习卡中核对。部分中文仍是完整论点的**语境提示**，并非逐词翻译。原材料的概括性论点不作为核实过的事实。原 PDF、封面与推广内容不上传。

数据生成顺序（仓库根目录）：

```sh
python3 writing/scripts/build-data.py
python3 writing/scripts/build-collocations.py
python3 writing/scripts/build-essays.py
python3 writing/scripts/build-sentences.py
python3 writing/scripts/build-course.py
python3 writing/scripts/build-usage.py
npm test
python3 -m http.server 4176 --bind 127.0.0.1
```

浏览 <http://127.0.0.1:4176/writing/>。无需打包、密钥或前端框架。

- `data/content.json`：旧版词库、例句与话题语境，维持兼容。
- `data/collocation-bank.json`：完整搭配、来源覆盖审计、关联小组。
- `data/sentences.tsv`：按 320 处原文多搭配论点逐条编辑的中英整句；其中一处误连的长清单按不同意思恢复为 6 项。
- `data/sentence-bank.json`：整句和独立短语课程、原搭配对应关系、来源审计与旧条目存档。
- `data/essays.json`：完整范文、中文提示、参考表达与论证说明。
- `data/course.json`：前端使用的组合课程清单。
- `core.js`：词汇/搭配练习、纠错、复习与旧进度恢复。
- `course.js`：板块进度、范文草稿、核对与错空重练。

## 保存与验证

词汇、搭配、旧造句继续使用 `zhihan-writing-v1`；范文独立使用 `zhihan-writing-course-v1`。不会读取或覆盖听力存储。所有记录仅在当前浏览器中保存，不跨设备同步；可导出 Markdown 备份学习记录。间隔复习是学习安排，不保证记忆效果。

测试覆盖来源全量入组、话题与范文关联、完整文章与填空位置、未练项选择、纠错次数、刷新续练、旧流程兼容、范文提交门槛、错空历史和文本转义。浏览器验证覆盖完整学习流程、中文翻译题、按需语音调用、无自动播放、用法提示、中文提示先行、手机布局及存储隔离。实际设备发音需由学习者试听确认。

### 用法资料维护

`data/usage-words.tsv` 保存经过整理的单词用法，`scripts/build-usage.py` 将它与明确的语法模式、搭配规则合并生成 `data/usage.json`。指南覆盖当前词汇、场景表达及历史条目；有匹配的整句或本站范文时附上可追溯例句，并非每条都有独立例句。重新生成课程后须再次生成用法指南。原来的听音偏好更新为中文提示，音量、纠错次数、记录和正在进行的纠错保持不变。翻译核对本次目标表达，不判定所有可能的合理译法。
